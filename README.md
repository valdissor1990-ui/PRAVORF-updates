# ПравоРФ — официальные обновления

Этот публичный репозиторий содержит только установочные APK и метаданные обновлений приложения «ПравоРФ». Исходный код приложения находится в отдельном закрытом репозитории.

Приложение проверяет наличие новой версии по адресу:

`https://raw.githubusercontent.com/valdissor1990-ui/PRAVORF-updates/main/update.json`

Релизы и APK публикуются автоматически из закрытого репозитория после подписанной сборки.
